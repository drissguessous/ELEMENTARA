# Elementara – instructions for agents

- Stack: TypeScript + Babylon.js 9 (3D), Babylon GUI (UI), Vite, Capacitor (Android/iOS). No physics engine: gameplay physics is `src/game/physics.ts`.
- Talk to the project owner in French. UI strings live in `src/i18n.ts` (fr + en); never hard-code player-facing text.
- **Never modify, redraw or reinterpret the characters.** `art/original/` is read-only. Derived assets (cutouts, resized, blurred backdrops) go in `public/assets/` and are generated by scripts.
- 3D heroes: models must use the Mixamo skeleton; wire them via `model:` in `src/config/heroes.ts`. Pipeline: `docs/ASSET_PIPELINE.md`.
- Child safety is a product requirement: no blood/gore, no free chat, no ads, no data leaving the device, parental gate before any setting.
- Keep the simulated dataset (`src/data/simulation/seed.json`) usable for demos whenever the data model changes.
- Before pushing: `npm run build` must pass. Visual QA: build, `npx vite preview`, screenshot screens with Playwright via deep links (`?screen=parcours&world=volcano&level=0&fixedres=1`).
- GitHub issues must be written for an agent: unambiguous, with links to the files and sections involved.
