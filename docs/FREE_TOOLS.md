# Outils et bibliothèques gratuits

Toujours vérifier la licence de chaque élément avant publication sur les stores et le noter dans [CREDITS.md](CREDITS.md). Préférer **CC0** (aucune obligation) ; **CC-BY** impose de citer l'auteur.
